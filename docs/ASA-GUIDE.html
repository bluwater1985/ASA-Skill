ASA (AI Software Architect) v3 开发者完全指南

版本： v3.0.0 (物理冻结版) | 日期： 2026年8月22日

ASA 是一个零外部依赖的 AI 协同工程管理框架。它通过高契约的节点矩阵、状态机拦截与 ACID 级崩溃事务自愈锁，将 AI 从“代码生成器”升级为对项目全生命周期行为进行自我约束和严谨追溯的架构师。

🎯 核心定位： ASA 完美原生兼容 Claude Code 和 Gemini CLI 双平台。刻意追求 0 外部 npm 依赖，纯基于 Node.js 原生 API 构建。

🚀 一、三契约层级运行总纲 (Three-Tier System)

运行层级 防护烈度 核心防守与验证机制 适用场景
Tier 1 - Starter 基础自律 会话启动强制只读诊断 diagnose，按 meta.phase 规律推进。 微型项目或开发自举初期。
Tier 2 - Defender 离线防御 启用 check-work-order PreToolUse 拦截与 pre-commit 静态门禁。 小团队或大中型模块，防半路漂移。
Tier 3 - Contract 强力契约 强制关联活跃任务（Work Order），代码改写前必须执行 set active-task。validate CI 级卡门。 极度要求覆盖率与高保真对账的重型工程。

🔧 二、24 核心命令终极指南

A. 基础与同步 (Sync & Baseline)

  • node .asa/index.js reconcile：状态一致性对账。若 matrix.yaml 损坏，可自举重建并做 Tab 写法软化迁移，自动产生 reconcile-pre-v3 全量物理备份。支持只读 -r 路由。
  • node .asa/index.js compile：正向编译。读取 nodes/ 级数据，编译产生 docs/01-requirements.md 与 03-tasks.md，保留手写散文备注与注释头尾。
  • node .asa/index.js patch：反向反写。解析 01-requirements.md 中人工补充的验收标准 acceptanceCriteria 并反向刷回 YAML。
  • node .asa/index.js validate [--json]：CI/CD 拦截门禁。严格哈希指纹对账、对 00/02 设计文档进行叙事锚点对账、校验节点漂移与未尽传播。
  • node .asa/index.js traverse ：图 BFS 拓扑遍历。输出该节点的下游 Blast Radius JSON。

B. 状态机与工作秩序 (Work Order & Approval)

  • node .asa/index.js status ：按照 strict 状态机模型原子流转状态，同状态跳转幂等拦截。
  • node .asa/index.js set phase ：设置项目开发阶段（可选：init, discovery, architecture, task-breakdown, implementation, review）。
  • node .asa/index.js set active-task ：锁定、激活当前开发的任务，是 PreToolUse 写入门禁的前提卡点。set active-task clear 退出。
  • node .asa/index.js confirm-task ：[架构师专属审核] 确认完成任务，将其推进至 completed。
  • node .asa/index.js reject-task --reason "<理由>"：[架构师专属审核] 驳回任务并赋予被拒修改意见，退回 in_progress 状态以供修复。
  • node .asa/index.js cancel-task ：安全取消特定任务，归零其活跃状态。
  • node .asa/index.js deprecate ：级联废弃（REQ 变 deprecated / ARCH 变 superseded / TASK 变 cancelled），其下游未完成 TASK 均自动级联取消。

C. 变更传播 (Propagation & Traceability)

  • node .asa/index.js impact ：变更影响分析。递归计算上游依赖（溯源）和下游爆炸半径影响树。
  • node .asa/index.js propagate ：幂等动作传播。级联执行 pendingPropagation 动作，并在局部失败时保留为 partial。
  • node .asa/index.js change-req|change-arch|change-task ：引导式阶段变更入口，先原子生成 matrix-pre-change 备份快照。
